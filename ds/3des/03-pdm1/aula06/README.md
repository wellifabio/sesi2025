## Protótipação com Figma
Um protótipo é uma ótima maneira de apresentar um produto (Em nosso caso um site, um projeto web full-stack ou um App mobile) a um cliente.<br>É uma ferramenta com funcionalidas reduzidas geralmente com uma boa apresentação gráfica para conquistar um cliente.
