# Aula05 - Projetos (Full Stack)

## Demonstração
- [Biblioteca Full-Stack](https://github.com/wellifabio/psof2-biblioteca-2025.git)

## Atividade
- Clone o projeto, não é necessário fazer fork.
- Execute em seu computador
- Crie uma estilização CSS para o projeto
- Habilite os formulários em forma de **Modais**
- Realize testes
  - Cadastre 10 livros,
  - Cadastre 5 alunos,
  - Cadastre 7 alugueis,
  - Cadastre 3 devoluções, pelo menos uma com mais de 3 dias para verificar o calculo da multa.
