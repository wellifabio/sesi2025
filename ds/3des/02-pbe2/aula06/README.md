# Aula06 - VPS01
Verificação Prática Somativa 01

## Situação de aprendizagem
### Contextualização:
Você faz parte de uma equipe de programadores e o SCRUM Master alocou um projeto com algumas tarefas/requisitos para você desenvolver no dia de hoje
### Desafio:
Na tabela abaixo, a frente do seu nome encontra-se o link do projeto que você deve fazer **fork**, deixar público e desenvolver as funcionalidades conforme requisitos descritos no `README.md` do projeto.<br>Após fazer **fork** clone o seu projeto e implemente as funcionalidades e faça commit conforme instruções de entrega.

## Entrega:
- Ao concluir o desenvolvimento, faça **commit** no seu repositório público, para que o SCRUM Master possa validar suas implementações e enviar para o time de **Q.A.** testar
- O projeto deve seguir a seguinte estrutura de pastas:
- `api/` contendo o código fonte do projeto.
- `docs/` contendo o arquivo **insomnia.json** exportado com os casos de teste.
  - `docs/prints` contendo prints de cada **caso de teste** 
- Arquivo `README.md` além das informações que já possui preencha as **Tecnologias utilizadas** e o **Passo a Passo de como executar a API** com um tutorial de instruções de como executar o projeto.

## OBS:
- Preste atenção nas orientações de entrega, pois a avaliação será conforme os commits realizados.
