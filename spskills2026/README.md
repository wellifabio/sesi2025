# Seletiva SPSkills 2026

## Situação 01
### Contextalização
Você é um programador júnior e recebeu a missão de desenvolver um sistema de gerenciamento de tarefas. O objetivo da aplicação é tornar o dia a dia do usuário mais organizado e produtivo, listando as atividades diárias que precisam ser desenvolvidas.

## Desafio
- Desenvolver um sistema com **linguagem C** onde o usuário terá a possibilidade de listar todas as tarefas pendentes para o seu dia, visualizando sua descrição e horário.
    - Quando concluída uma atividade poderá marcar a tarefa como finalizada.
- Para desenvolver essa aplicação será necessário construir uma **documentação** contendo os requisitos necessários para o funcionamento, um protótipo da interface mobile (canva ou figma).

## Entregas
Crie um repositório do github com um arquivo README.md contendo o endereço do protótipo figma, uma pasta para o arquivo ou arquivos em linguagem C e uma pasta para a documentação pode ser em PDF ou Markdown.

** Não será aceito o uso de IA’s **
